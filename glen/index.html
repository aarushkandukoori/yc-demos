Context Reef

A toy demo of a shared learning layer for agents. Toggle which fragments of team history are "in the water" — a diff, a Slack thread, a ticket, a doc — then run the same prompt through a naive single-source agent versus one that reconciles across all of them. Everything below is synthetic sample data.
