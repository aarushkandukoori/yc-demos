Groundtruth

A toy fact-fusion engine. Type a place, watch it query several disconnected "silos" of physical-world data (parcels, utility feeds, environmental sensors, census blocks, permits) and merge them into one cited answer — the way an agent would need to, if it could actually see the ground.
