Teach-once assembly cell

Demonstrate a 3-part build one time. The cell records your pick and place moves, then repeats it for a whole batch. Parts never land in exactly the same spot, so you can watch blind replay fail and camera correction fix it, at a cost in cycle time.

1. DemonstrateMove parts to the fixture, base first
2. Program savedWaypoints recorded
3. Run a batchCell repeats it alone

Dashed circles = where the taught program will grab (grasp tolerance 12 px).
Blind replay misses when the real part sits outside that circle.
Camera mode re-locates every part first, so it never misses, but each pick takes longer.
Keys: R = run batch, X = stop.

Click a part on the left tray, then click its outlined slot on the fixture.
