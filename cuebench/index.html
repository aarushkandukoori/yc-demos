Measurement Budget

A chaotic double pendulum traces a path you can't fully see. You get a handful of measurements to spend on when to look. An agent in the background searches, by trial and reward, for the measurement schedule that reconstructs the path best — the same loop behind training a model to decide where to spend a limited "look" in a scientific-reasoning task.

Agent training progress

Each episode the agent tweaks one measurement time, keeps it if the reward improves, and occasionally keeps worse moves early on to keep exploring.

Why this matters: the hard part of a lot of real scientific and engineering work isn't computing an answer once you have data — it's deciding where to spend a scarce, expensive measurement (a wet-lab assay, a profiler trace, a wall-clock-expensive simulation step) so the answer you reconstruct is actually trustworthy. This toy swaps "measurement" for points on a pendulum's path, but the search loop — propose, score, keep what works, repeat — is the same shape as RL post-training on a task with a sparse, expensive reward.
