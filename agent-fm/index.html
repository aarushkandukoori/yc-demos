Squadcast

A toy demo: three coding agents work in parallel and post their progress, blockers, and decisions into one shared channel. You steer them by replying — no tab-switching between terminals required.

Live agents

Every bubble below is generated by a scripted simulation running entirely in this page — nothing is sent anywhere. Click a suggested reply or type your own to steer an agent.
Tip: mention an agent by name (e.g. "hey Nyx, use retries") to steer it directly.
