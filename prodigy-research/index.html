Feature Weights the Model Is Using Right Now

This toy model scores each tick on four synthetic features — spread z-score, short-term momentum, mean-reversion pull, and volatility regime — combines them into one confidence number, and only opens a position when confidence clears a threshold. Position size scales with confidence, and the hedge leg (BETA) is sized to keep net delta near zero, mimicking a market-neutral book.
