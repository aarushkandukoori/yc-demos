Synapse Trace

A toy structural graph of a synthetic codebase. Click any function to trace its blast radius — every symbol that transitively depends on it, grouped by hop distance with a decaying confidence score. No embeddings, no guessing: just the call graph, walked backwards.

Select a symbol on the left. Synapse Trace will walk the call graph upward and list every caller (direct and transitive) that would be affected if that symbol's behavior changed — the same "blast radius" an agent needs before it safely edits code.
