Close the laptop. The build keeps going.

A tiny simulation of a persistent cloud dev session: kick off a long-running job, "close your laptop," come back later, and reattach to find the terminal exactly where you left it — output and all.

you@remote-box:~/app — tmux session "main"
● attached
Welcome back. Session "main" has been running for 0s.
Try: run build | run server | ls
$

Your Laptop
