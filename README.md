# yc-demos

Mini-demos built by **[Aarush Kandukoori](https://aarushkandukoori.com)** — one
small, original interactive demo per YC S26 company I've reached out to, each
inspired by that company's public product and docs and linked from the email I
sent them.

Everything in this repo is my own build and property. No demo is affiliated
with, endorsed by, or derived from non-public material of the company it
references — company names appear only to credit the inspiration, and every
page says so in its footer.
