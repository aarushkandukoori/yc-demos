Pixel-Native Filtering — a toy simulation

A conventional edge camera captures a full frame, ships every pixel to a GPU, and only then decides what mattered. This demo simulates an alternate architecture: a tiny neural filter runs inside each pixel, so the sensor itself decides what's worth reporting — and only that sparse signal ever leaves the chip. Synthetic data only; nothing here talks to a network.

The mechanic: each of the 432 photosites has its own toy activation function fire = f(intensity, local_contrast) > threshold, evaluated locally, in parallel, before anything reaches an output bus. Raise sensitivity and the filter fires on more marginal pixels, catching subtler signal at the cost of bandwidth. Raise noise and you'll see the filter start false-firing on sensor grain — the same tradeoff a real in-pixel classifier has to make.
