Stackyard

A toy git forge for teams where humans and agents both push. Pull requests merge as a stack — each one only becomes mergeable once everything below it in the stack is merged and its own checks are clean. Run checks, watch merge-readiness update live, and land the stack in order.

Merge order is enforced bottom-up: PR #1 must land before #2 can even be considered, no matter how green its own checks are. That's the mechanic real stacked-diff review depends on — this demo computes it live as you merge and re-run checks.
