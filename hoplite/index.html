Foreman — hand it a ticket, watch it ship

A toy simulation of a cloud dev agent: point it at a repo, describe the task, and it plans, edits, tests, and opens a pull request in an isolated sandbox — pausing whenever it hits something that needs your say-so. Everything below runs entirely in your browser with fake data; no repo is touched.

rate limit checkout fix flaky webhook retry add health endpoint

2. Agent thread

Pick a repo and a task, then click "Assign to agent" to start a run.
