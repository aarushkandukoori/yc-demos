Red Cell // Autonomous Agent Breach Simulator

A toy version of continuous adversarial testing for AI agents, inspired by Fabraix's Nyx. Pick a target defense posture, choose an attack payload, and watch a simulated red-team agent try to break it — no real network calls, everything below runs in your browser.

Target Configuration

Simulated target: a customer-support agent with tool access (refunds, order lookup, email). It reads documents, tickets, and tool outputs — any of which could carry a hidden instruction.

Toggle defenses to see how they change what gets through. Real security posture is rarely this legible — that's the point.
