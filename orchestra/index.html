Distillery — a self-optimizing inference queue

This is a homage demo, not a real product. It simulates a repetitive workflow (classifying contract clauses) being run against an expensive "frontier" model. Every production run is captured as a training example for a small model. Once the small model's held-out accuracy matches the big one, the router switches traffic over — automatically, mid-stream.
