Rebuild & Compare

A running enclave can prove it is running some binary. This toy shows the missing half: proving it is the binary that this reviewed source produces. Everything runs in your browser with synthetic data and a toy trust root.

1 Edit and commit source 2 Build deterministically and deploy 3 Auditor rebuilds and checks the attestation 4 Play the malicious admin and watch it fail

1 Source repository

Edit any file, then commit. Commits are the "reviewed source" an auditor can point at.

2 Build & deploy

The builder hashes every input into layers, then hashes the layers into one image measurement.

Tip: build the same commit twice with the checkbox off and the measurement never changes. Turn it on and it changes every time, so nobody could ever reproduce it.
