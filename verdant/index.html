Permit Copilot — reviewer-in-the-loop demo

A toy version of the core mechanic behind AI-assisted permitting: an agent reads a submitted application against the relevant code sections, checks it for completeness and conflicts, and produces a recommendation with a confidence score — leaving the actual approval to a human reviewer. All applications and rules below are synthetic.
