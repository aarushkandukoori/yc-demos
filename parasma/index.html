Neuron Trainer // living-cell compute sandbox

A toy simulation of training a culture of biological neurons to predict the next symbol in a stream — the same core loop researchers use to get real neuron cultures to do useful computation: stimulate electrodes, read the response, reinforce whatever synapses predicted correctly. Everything here is a simplified numerical model, not real tissue.

Learned receptive fields (synaptic weight map per symbol)

For each output symbol, this shows which electrodes the culture has learned to associate with predicting it next. Blue = excitatory (reinforced), red = inhibitory (suppressed). On a learnable stream these sharpen into distinct patterns; on the random stream they stay noise.
