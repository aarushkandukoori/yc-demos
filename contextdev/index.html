What's actually happening: the "raw page" text is synthetic markdown standing in for a rendered page. Extraction here is simple substring/pattern matching against that text — a real pipeline would use layout-aware parsing and a model to fill fields a schema-matcher can't find by pattern alone (e.g. inferring "in_stock" from a whole sentence). The point this demo makes is the shape of the contract: give it a schema, get typed values back, on every page, on every refresh.
