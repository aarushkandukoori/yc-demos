sentence→arena

Toy demo: type one sentence, a parser compiles it into a game spec (JSON), and a tiny engine instantly runs it as a local multiplayer game. Edit the sliders to remix the spec live. Everything runs in this page, no network, no model: the "generator" is a keyword compiler standing in for an LLM.
