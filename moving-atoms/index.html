Rollout Lab · toy demo

Nudge the block. Watch a toy world model predict what happens next.

Drag inside the action pad to set a push (direction + force) on the block, like an action-conditioned world model would receive from a robot policy. The model rolls forward its own predicted physics without seeing the real simulator, frame by frame, then we overlay both and score the divergence — the same idea behind benchmarking a world model against ground-truth rollouts.
