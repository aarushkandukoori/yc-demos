Etch-a-Model

A toy of one idea: a normal chip fetches a model's weights from memory for every token, a hardwired chip has them etched into its wiring. Both below run the same tiny language model. Generate some text and watch what each one has to move.

Weight matrix (4-bit): click a cell to corrupt DRAM

Rows are the current word, columns the next word. Brighter means more likely. Click a cell: the programmable core's copy changes at once. The hardwired core cannot be edited, it needs a new tape-out.

What is real here, what is made up

    
Real: both cores run the same 4-bit word-pair model built from a small made-up corpus in your browser, and with the same seed they produce identical text. The hardwired core is genuinely compiled from the weights into a function made only of constants. Made up: the energy and speed numbers come from a toy cost model (illustrative figures: a 32-byte DRAM burst costs 3.2 nJ and 8 cycles, a fixed constant multiply costs a tenth of a programmable one). The trade-off is real too: etched weights are fast and cheap but frozen.
