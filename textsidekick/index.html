Frontline Radio

A toy demo of the core mechanic behind text-first shop-floor assistants: a worker texts in plain language, the assistant answers from a knowledge base when it can, and quietly turns every unresolved case into a routed work order and a new knowledge entry — so the answer only has to be given once.
