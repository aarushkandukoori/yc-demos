What just happened: the canvas session on the left never left your browser. As you drew, every pointer-down, pointer-move, pointer-up, and tool switch was appended to an in-memory trajectory — { t, type, x, y, tool, target } — the same event schema (compressed here for the demo) that underlies expert computer-use datasets. Hitting Replay trajectory discards the canvas entirely and reconstructs the whole session from that event list alone, proving the log is a faithful, model-trainable substitute for the recording itself.
