Autoplan — Generative Facility Layout (toy demo)

Set a target IT load and site envelope, then generate an engineered data hall layout: white space, cooling plant sizing, electrical capacity and a rough construction cost — recomputed from first principles in your browser, not fetched from a database. This is an independent homage demonstrating the core mechanic of AI-driven facility design automation, not Marengo's actual software.
