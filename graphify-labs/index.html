Proofline — stop guessing whether a refactor is safe

Proofline builds a live graph of your codebase's functions and their call relationships, then formally checks every proposed change against it: either it proves the new code behaves like the old code for the whole input domain it can reach, or it hands you back the exact input that breaks it. Pick a pull request below and run the checker — this is a simplified, in-browser version of that core mechanic, evaluated live against real JavaScript, not a canned animation.
