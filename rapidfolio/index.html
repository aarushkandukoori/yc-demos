casework

A toy back office. A KYB procedure written in plain English compiles into deterministic checks, works a queue of fictional business applications, and replays every past case before a new version of the procedure can ship.

  1. Write the procedure
  2. Each line compiles to a check
  3. The agent gathers and seals evidence, the procedure decides
  4. Edit a line: past cases replay before you publish

Start with Work the queue, then edit a line of the procedure.
