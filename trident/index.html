Chainwalk - attack paths that have to survive a replay

A toy agent explores a synthetic company ("Northwind Parcel", all fake). It proposes exploit steps, replays each one from a clean session, and only keeps what reproduces. Then it chains the survivors into a path to the production database. Apply a fix and re-run to watch the path reroute or die.
