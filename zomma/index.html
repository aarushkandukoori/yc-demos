Gatekeeper: an agent you can only deploy after it passes your own old cases

A toy of one idea: a screen-driving agent follows a written procedure, gets scored against past reviewer decisions (including cases it must refuse), and only then gets a queue. Edit the procedure and the score goes stale. All data is synthetic.
