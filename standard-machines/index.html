How it works

State is the cell positions. An action moves one cell (or swaps two). Wirelength is half-perimeter of each net's bounding box. Congestion counts how many net boxes overlap each 4x4 region beyond a capacity of 6. Reward = -(wirelength + weight x congestion). Annealing accepts worse moves with probability exp(delta / T) while T cools, so it can escape local minima that greedy gets stuck in. Try the three policies from the same scramble.
