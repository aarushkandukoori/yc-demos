Switchboard - one agent identity, four channels, one memory

A toy model of an agent that owns an inbox, a phone number, an iMessage handle and a peer-to-peer address. Messages from the same person on different channels resolve to one contact, access rules gate each channel, and the agent can hand work to another agent. Everything runs in your browser on synthetic data.
