Silent Failure Miner

A toy version of the core idea behind reading agent transcripts: scan raw conversations between a support agent and its users, surface the turns where the agent looked fine but quietly failed, cluster the recurring failure patterns, then simulate distilling a smaller model on just those hard cases.
