Operator Relay — human-in-the-loop dispatch demo

A toy warehouse robot drives itself until it hits something it can't resolve alone. At that point it opens a teleop request — like an API call, but the handler on the other end is a person. You are that person. Take the stick when it pings you, clear the blocker, hand control back. All data below is synthetic.
