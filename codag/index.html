Signal Sieve

A toy proxy that sits between a coding agent and its tool output. Big, noisy results (test runs, grep hits, file listings) get sieved down to the lines that actually carry signal — everything else stays on disk, addressable by line range, not deleted. Diffs and source stay untouched, always. Pick a sample tool result below.
