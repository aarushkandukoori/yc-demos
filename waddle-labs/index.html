GantryLoop

Type a manipulation task in plain language. An agent drafts a motion policy, executes it on a simulated arm, watches whether it actually worked, and rewrites the policy on failure — no human in the loop. This is a toy stand-in for the write → test → improve cycle behind agents that control real robots.
