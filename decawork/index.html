Fleet Deck / agent governance sandbox

A toy control plane for internal AI agents. Every agent runs with a scoped credential set. Actions inside scope go straight through; actions that touch something sensitive stop and wait for a human sign-off before the agent is allowed to continue. Nothing here calls a real system — pick an agent and hit run.
