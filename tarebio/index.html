Imprint Reader: stop guessing antigens, read them off the immune system

Most vaccine design starts by predicting which molecular fragments (antigens) might trigger an immune response, then testing that guess. This toy flips the order: it samples immune cells that are already fighting a synthetic tumor, measures which candidate antigens they actually react to, and assembles a vaccine cocktail from that signal — no prediction step. Then it races that cocktail against a blind-guess vaccine so you can see why reading beats guessing.

1 Generate a synthetic patient

Creates a patient with a tumor expressing a hidden set of driver antigens, drawn from a library of 16 candidates. The identities are hidden from you — the same way they'd be hidden from a vaccine designer working from prediction alone.

2 Read the immune imprint

Simulates sorting circulating T-cells and measuring how strongly each reacts to every candidate antigen. Real driver antigens produce a strong, consistent signal; everything else is noise. This is the "one input" the whole cocktail gets built from.

3 Reverse-engineer the vaccine cocktail

The algorithm takes the top-signal antigens from the imprint read and proposes them as the vaccine payload — the antigens the patient's own immune system already flagged as worth attacking.

4 Deploy & compare against a blind guess

Two identical synthetic tumors, 140 cells each. The left is treated with your imprint-derived cocktail; the right is treated with a same-size vaccine picked without reading the imprint — the traditional "predict and hope" baseline. Each simulated round, a cell's odds of being cleared scale with how many of its true driver antigens the deployed vaccine actually targets.

This is a deliberately simplified model — one static "imprint read," uniform per-cell odds, no real biology, sequences, or lab data. It exists to show the shape of the idea: build the vaccine from what the immune system already recognizes, not from a prediction of what it might.
