SignalSqueeze: watch a chip trace shrink in real time

Every chip debug session starts with a waveform dump — a recording of every internal wire, every clock tick, for the entire test run. Raw, that's enormous. This demo generates a synthetic 4-signal trace, then compresses it the way a smart waveform codec would: exploit the fact that most wires barely change between adjacent cycles.

What's actually happening: the codec walks the trace cycle-by-cycle per signal. If a signal's value is identical to the previous cycle, it emits nothing — the decoder just holds the last value (run-length skip). When a value does change, it emits a compact (delta-cycles, new-value) pair instead of a full timestamped sample. On a real chip trace, most wires sit idle for thousands of cycles between toggles, so this alone removes the vast majority of redundant data — which is the same insight full waveform codecs are built around, just without the bit-packing, dictionary coding, and cross-signal correlation a production version would add on top.
