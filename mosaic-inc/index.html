Relay

A toy shared-memory layer for people and agents working the same project. Every action gets written to one timeline with the reasoning attached — so anyone (or any agent) who joins later can catch up instantly instead of re-deriving context. Pick an actor, log an action, then simulate a new teammate joining cold.
