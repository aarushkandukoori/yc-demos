TwinBench - a toy digital-twin builder

Company data goes in on the left. A consistent pseudonym map turns it into a safe twin on the right. Then an agent has to solve a task that crosses Slack, Jira and email, using only the twin. Break the consistency and watch the task die.

Raw company data (editable, fully synthetic)

Twin (what an RL environment would see)

Task

Who is the root blocker for the Brightwater renewal, and by what date must they finish?

    The agent is a small scripted tool-user (search, open, cross-check). The grader compares its answer to the raw answer pushed through the same canonical mapping. Ticket IDs are kept as structure.

    Independent demo built by Aarush Kandukoori, inspired by Ooak Data (YC S26). Not affiliated with Ooak Data.
