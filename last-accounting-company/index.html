Postbook - toy demo

An agent turns raw bank lines into double-entry journal entries. Confident ones post themselves; shaky ones wait for an accountant. Every approval teaches the agent a vendor rule. All data is synthetic and runs in your browser.

  1. Run the agent. New vendors score low and land in the queue.
  2. Approve them. The agent saves a rule and gets surer next time.
  3. Fetch more lines and run again. Repeat vendors now post themselves.
  4. Once the queue is empty, the accountant signs off the period.
