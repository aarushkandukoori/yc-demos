Wetware Sandbox — training a task with synapse-local reward, not backprop

This is a toy simulation of the core idea behind growing biological neurons into a training substrate: weights that live directly at the synapse and update from a local reward signal, instead of being shuttled to a separate compute unit for a global gradient step. Below, a five-neuron patch learns to steer a "frog" across a river of columns using nothing but per-synapse reward-modulated plasticity — the same family of learning rule real cortical tissue uses. Click around, watch the synapses thicken as they learn.

1. Live culture — reward-modulated Hebbian learning

Five input neurons (one per column) drive three output neurons (steer left / hold / steer right). Every synapse updates independently, in place.
