Redline Bench

A toy test-sequence runner. Write a firing sequence and redlines as code, inject a fault into a simulated rig, and watch abort logic fire off live telemetry. All data is synthetic.

Sequence + redlines (as code)

Inject fault

Syntax: T+2.0 open V_PRESS T+3 close V_FEED T+0 set REG 60 redline P_TANK > 90 for 0.3 -> abort. Abort closes pressurization and feed, opens vent. Try the faults, then loosen or tighten a redline.
