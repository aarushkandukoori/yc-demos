Diagnostic Path

A small toy that shows the core mechanic behind vehicle-specific failure diagnosis: pick a vehicle and symptoms, and watch it rank likely root causes with the specific test that confirms or rules out each one — instead of a flat list of "possible causes."

Intake

Ranked causes & confirming tests

Select a vehicle and at least one symptom.
This demo simulates what the real system does: cross-reference the reported symptoms against known failure patterns for that specific vehicle, then order candidate causes by likelihood and attach the one test that would confirm or rule out each one — so a tech knows exactly what to check first instead of guessing.
